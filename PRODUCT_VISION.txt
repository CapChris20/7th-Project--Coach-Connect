ANATROX AI — PRODUCT VISION & ROADMAP
======================================

Purpose: Living document for app vision and direction. Will be updated as more context is added.

---

1. CORE FEATURES
----------------

A. Trainer-First CRM
   - Client Management: Trainers can onboard, organize, and message clients.
   - Workout & Meal Plan Assignment: Trainers assign structured programs to clients.
   - Adherence Tracking: Trainers monitor client progress (workout completion, nutrition logs).

B. AI-Generated Workout Framework
   - Onboarding-Driven: Clients answer detailed questions about goals, experience, equipment, schedule, and limitations.
   - Claude-Powered Plan Generation: AI generates a 4–8 week workout plan with:
     * Clear progress feedback during generation.
     * Ability to regenerate or customize plans.
   - Editable Plans: Clients/trainers can tweak generated plans.

C. Nutrition Tracking
   - Simplified Logging: Uses the USDA FoodData Central API for calorie/macro tracking.
   - Trainer Visibility: Trainers see client logs for accountability (not micromanagement).

D. Progress Tracking
   - Metrics: Weight, photos, workout completion.
   - Voice AI: Push-to-talk feature for fitness/nutrition questions (strict usage limits, context-aware).

E. Business Model
   - Subscription: Trainers pay a monthly fee.
   - Client Onboarding: Clients join via trainer invites or an opt-in trainer directory. The directory is a discovery tool (helping clients find trainers), not a marketplace (no rankings, commissions, or pay-per-lead).
   - No In-App Payments/Commissions: No rankings or monetization of client-trainer interactions.

---

2. TECHNICAL STACK
------------------

Frontend:     React Native (cross-platform mobile app)
Backend:      Firebase (auth, Firestore, real-time) — no Supabase
AI APIs:      Claude (workout plan generation), USDA FoodData Central (nutrition data)
Voice AI:     Custom push-to-talk integration

---

3. UNIQUE VALUE PROPOSITIONS
----------------------------

- Trainer-Centric: Focuses on empowering trainers, not just clients.
- AI-Assisted, Not AI-Driven: AI generates plans, but humans (trainers/clients) retain control.
- Anti-Micromanagement: Nutrition tracking is intentionally simple to avoid obsessive behavior.
- No Marketplace Dynamics: Avoids gamification, commissions, or rankings that commodify training.

---

4. REAL-WORLD FOCUS
-------------------

- Production-Grade: Designed as a realistic product, not a toy project.
- Data & Product Thinking: Emphasizes practical UX, scalability, and ethical AI use.

OFFICIAL NUTRITION DATA SOURCES (order they fire):
--------------------------------------------------

1. USDA FoodData Central
   - Free, public domain, no credit required
   - Best for: generic foods, fast food chains, branded items from manufacturers
   - Has McDonald's, Wendy's, Chipotle, Subway, Chick-fil-A already
   - No rate limits on free tier with API key
   - Get key at: fdc.nal.usda.gov

2. Open Food Facts
   - Free, one-line credit required in app settings
   - Best for: packaged foods with barcodes (protein bars, cereals, frozen meals)
   - Barcode scanner database
   - No API key needed
   - world.openfoodfacts.org/api

3. Web Search + LLM Extraction (Serper)
   - ~$50/month for 50k searches; free tier to start
   - Best for: obscure chains, regional restaurants, new menu items
   - User explicitly triggers it, not automatic
   - Show "Estimated from web" badge
   - Results save to Firestore foods collection so next user gets it instantly

4. Manual Entry
   - Free, always available, zero dependencies
   - User types macros themselves
   - Saves to their personal foods collection
   - Ultimate fallback when everything else fails

ORDER: USDA → Open Food Facts → Web Search (user triggered) → Manual Entry
