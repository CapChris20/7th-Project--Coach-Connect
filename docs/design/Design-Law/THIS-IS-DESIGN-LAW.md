# Design Law (authoritative)

This folder is the **only** visual + system contract for Coach Connect redesign work (Chris + Shane).

## Priority order when something conflicts

1. `screens/<flow>/*.png` — what the UI must look like (light + dark)
2. `DESIGN-SYSTEM.md` — tokens, shapes, components, motion
3. `mockups/*.html` — interactive reference for structure / behavior in the phone
4. `MAPPING.md` — which repo files to change for each flow

Anything that does not match these screens is wrong. Older docs, cool-gradient chrome, or invented layouts are not law.

Do not delete this folder. Do not move it under `src/`.
